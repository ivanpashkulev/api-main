# LinkedIn About — Draft

I’m a Senior DevOps Engineer with a full-stack software engineering background and an end-to-end perspective: how an application is built, secured, deployed and operated.

At ICT Strypes, my work centres on Microsoft Azure, Azure DevOps, Infrastructure as Code and automation of enterprise cloud environments. With more than five years in DevOps, I bring a developer’s understanding of application architecture to infrastructure and delivery decisions.

My core toolkit includes Terraform, Ansible, GitHub Actions, Azure DevOps, Docker, Linux, Bash and PowerShell. I value readable code, reproducible environments and pipelines that make failures easy to diagnose. Clean Code principles guide how I approach infrastructure automation as much as application development.

Alongside my professional work, I’m building a practical multi-cloud portfolio. I have provisioned and deployed the same applications across AWS, Google Cloud and Azure, and now run my personal web platform on Hetzner. The work connects reusable Terraform modules, dynamic Ansible inventory, container deployments, Cloudflare and GitHub Actions—from infrastructure provisioning to working applications.

AI is a growing part of my engineering practice. I’m developing an AI assistant for my web platform using Python, FastAPI, LangGraph and OpenAI models, with streamed responses and context drawn from my professional background. I’m also exploring MCP and agent workflows, with a focus on useful integrations, maintainability and operational control.

Before DevOps, I spent nearly three years at SAP in full-stack development. My software background spans Java and Spring, JavaScript/TypeScript, React, Angular, Node.js and Python, supported by experience with relational databases and MongoDB. That foundation helps me connect application behaviour with the infrastructure it depends on.

Security is part of that perspective. I joined ICT Strypes’ penetration-testing team in 2024 and earned the OffSec Web Assessor (OSWA) certification, strengthening how I assess web application risks and delivery practices.

Earlier careers in radio production, DJing and ski instruction shaped my communication, adaptability and approach to teaching. Today, I bring that same curiosity to engineering.

I’m interested in conversations about senior DevOps and platform engineering opportunities where cloud automation, software engineering and practical AI meet.
